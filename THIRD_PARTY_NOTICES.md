# Third-party notices

The root Python reference harness uses only the Python standard library and incorporates no third-party source code. The optional external-ablation scripts require NumPy, pandas, SciPy, and PyTorch; their licenses are not reproduced in this package.

No third-party dataset is distributed in this repository. Dataset names, citations, identifiers, official links, and stated terms are provided in [`DATASETS.md`](DATASETS.md). Users are responsible for reviewing the current terms of each data provider before acquisition or reuse.

The external-ablation scripts import source modules from two pre-existing public-data experiment workspaces. Those source modules are not copied because no reusable software license was identified in the supplied directories. Users must supply legally obtained source workspaces through command-line paths and preserve the original notices. The derived CSV result tables are included as evidence, pending the repository owner's final license selection.
