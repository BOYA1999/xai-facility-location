# Data availability and access boundary

## Restricted case-study inputs

The study describes Guangzhou road-network data, census-block statistics, and disaster-risk maps as institutionally supplied inputs subject to redistribution restrictions. The revision archive used to prepare this release did not contain those source files, agreement identifiers, versions, access dates, derived grid-cell features, or a custodian-approved public access route.

Accordingly, these materials are not included here and this repository makes no promise that they can be obtained from the repository maintainers. Access must be requested from the original data custodians or an authorized institutional contact and remains subject to their approval, license terms, and any applicable data-use agreement.

## Public stress-test overlays

The NASA, USGS, and Global Flood Database resources listed in [`DATASETS.md`](DATASETS.md) are public external overlays. They were identified for failure-boundary stress testing only. They do not replace the restricted Guangzhou inputs and must not be used to claim that the case-study landslide polygon has been independently validated.

## Repository contents

This repository contains no raw, processed, derived, participant-level, geolocated case-study, or figure-source data. The smoke test creates synthetic values in memory and does not represent any person, household, city record, or reported experiment.
